Instalar Claude Code

La instalación la hacemos juntos en la primera sesión. Te enviamos esta guía antes para que tengas los pasos a mano y, si quieres, puedas adelantarla. Todos los comandos se han comprobado contra la documentación oficial a 2 de octubre de 2026.

Si te adelantas y algo fallaNo pasa nada: lo resolvemos en clase. Mira primero Problemas frecuentes. Si el error tiene pinta de bloqueo de la empresa (falta de permisos para instalar, proxy, antivirus, licencia), avisa a tu equipo de IT cuanto antes, con el mensaje exacto o una captura: eso solo lo pueden desbloquear ellos.

0 · Qué necesitas

RequisitoDetalle
Cuenta de ClaudePlan Team o Enterprise de la empresa (lo más habitual), o Pro, Max o una cuenta de Claude Console. El plan gratuito de claude.ai no incluye Claude Code. La invitación que te llega por correo tiene que estar aceptada antes de la sesión.
Sistema operativoWindows 10 versión 1809 o superior (64 bits), o macOS 13 o superior. También Ubuntu 20.04+ / Debian 10+.
Equipo4 GB de RAM o más. Procesador x64 o ARM64.
RedConexión a internet. Si estás detrás del proxy corporativo, mira la sección 6.
PermisosNo hace falta ser administrador. Claude Code se instala en tu carpeta de usuario.
Tu código (sesiones 5 y 6)Una copia en tu máquina donde puedas trabajar sin miedo, que no sea producción. En las sesiones 1 a 4 se usa el proyecto del curso, que se crea de cero.

1 · Claude Code en Windows

WindowsUsa el instalador nativo: es el método recomendado por Anthropic y se actualiza solo.

  1. Abre PowerShell (menú Inicio → escribe PowerShell → Enter). No hace falta abrirlo como administrador. Sabrás que estás en PowerShell porque la línea empieza por PS C:\Users\TuNombre>.
  2. Pega este comando y pulsa Enter: 
    irm https://claude.ai/install.ps1 | iex
  3. Cuando termine, cierra esa ventana y abre una nueva. La terminal antigua no ve los cambios del PATH.
  4. Sigue en la sección 3.

Si estás en CMD (Símbolo del sistema) en vez de PowerShell

La línea empieza por C:\Users\TuNombre>, sin PS. Usa este otro comando:

curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
Error típico: comando equivocado para la terminal
  • 'irm' is not recognized… → estás en CMD. Usa el comando de CMD o abre PowerShell.
  • The token '&&' is not a valid statement separator → estás en PowerShell con el comando de CMD. Usa irm ….

Alternativa: WinGet

Si vuestro departamento de IT prefiere instalar con WinGet:

winget install Anthropic.ClaudeCode
OjoInstalado con WinGet, Claude Code no se actualiza solo. Hay que ejecutar winget upgrade Anthropic.ClaudeCode de vez en cuando. No mezcles métodos: usa uno solo.

2 · Claude Code en macOS

macOSAbre la app Terminal (⌘ + espacio → Terminal) y ejecuta:

curl -fsSL https://claude.ai/install.sh | bash

Cierra la ventana, abre una nueva y sigue en la sección 3. El mismo comando vale para Linux y para WSL.

Alternativa: Homebrew

brew install --cask claude-code

Con Homebrew tampoco se actualiza solo: brew upgrade claude-code.

3 · Comprobar la instalación

En una terminal nueva:

claude --version
Resultado esperadoUn número de versión, por ejemplo 2.1.290 (Claude Code). El número exacto da igual.

Después, el diagnóstico completo (no abre sesión ni gasta uso):

claude doctor

Muestra el estado de la instalación, los ficheros de configuración y avisos con su solución. Si algo sale en amarillo o rojo, haz una captura.

"claude no se reconoce" / "command not found"La carpeta de instalación no está en el PATH. Solución en Problemas frecuentes.

4 · Primer arranque y login

  1. Ve a la carpeta de tu repositorio. Por ejemplo: 
    cd C:\repos\mi-proyecto
  2. Arranca Claude Code: 
    claude
  3. La primera vez se abre el navegador para iniciar sesión. Entra con la cuenta de la empresa (la de la invitación).
    • Si el navegador no se abre: pulsa c para copiar la URL y pégala en el navegador.
    • Si el navegador te muestra un código en vez de volver solo: pégalo en la terminal donde pone Paste code here if prompted.
  4. Verás Login successful. Pulsa Enter.
  5. Si te pregunta si confías en la carpeta, responde que sí solo si es tu repo de trabajo.
  6. Escribe /status y Enter. Comprueba que aparecen tu correo y la organización de la empresa.
  7. Sal con /exit (o Ctrl+C dos veces). El resto lo hacemos juntos en clase.
Si ya tenías otra cuentaSi iniciaste sesión antes con una cuenta personal, escribe /logout dentro de Claude Code y vuelve a entrar con la de la empresa. Si tienes la variable de entorno ANTHROPIC_API_KEY definida, Claude Code la usará en lugar de tu cuenta: avísanos.

5 · Git y Node.js (para el proyecto del curso)

Durante el curso construimos desde cero una pequeña aplicación web. Para eso necesitas Git y Node.js 22 o superior. Git guarda el proyecto en tu equipo, como punto de guardado: no necesitas cuenta en ningún sitio ni usarlo en tu trabajo. Comprueba los dos:

git --version
node --version

Si falta Node.js, pídeselo a IT o instálalo desde nodejs.org (versión LTS). En Windows su instalador suele pedir permisos de administrador.

WindowsClaude Code funciona sin Git for Windows: en ese caso ejecuta los comandos con PowerShell. Pero lo recomienda Anthropic, porque con él Claude Code puede usar Git Bash, y el proyecto del curso lo necesita. Si ya usas git en tu equipo, lo más probable es que ya lo tengas.

Para comprobarlo:

git --version

Si no está, descárgalo de git-scm.com/downloads/win, o con WinGet: winget install --id Git.Git -e. Después, cierra y abre la terminal.

6 · Red corporativa / proxy

Si la instalación o el login fallan con errores de red, certificados o 403, probablemente estés detrás del proxy de la empresa. Esto suele resolverlo IT.

Probar la conexión

WindowsEn PowerShell escribe curl.exe, no curl (en PowerShell 5, curl es otro comando):

curl.exe -sI https://downloads.claude.ai/claude-code-releases/latest

macOS

curl -sI https://downloads.claude.ai/claude-code-releases/latest
Resultado esperadoUna primera línea con 200 (por ejemplo HTTP/2 200).

Configurar el proxy

Pide a IT la dirección del proxy y, si hay inspección SSL, el certificado raíz de la empresa en formato PEM. En PowerShell, solo para la sesión actual:

$env:HTTPS_PROXY = "http://proxy.empresa.local:8080"
$env:NODE_EXTRA_CA_CERTS = "C:\certs\ca-empresa.pem"

Para que se aplique siempre, IT puede ponerlo en el bloque env de %USERPROFILE%\.claude\settings.json o en la configuración gestionada de la empresa.

Dominios que tienen que estar permitidos: api.anthropic.com, claude.ai, claude.com, platform.claude.com y downloads.claude.ai.

Arreglar el PATH en Windows

Comprueba si la carpeta está en el PATH:

$env:PATH -split ';' | Select-String '\.local\\bin'

Si no sale nada, añádela (solo para tu usuario, no necesita administrador):

$currentPath = [Environment]::GetEnvironmentVariable('PATH', 'User')
[Environment]::SetEnvironmentVariable('PATH', "$currentPath;$env:USERPROFILE\.local\bin", 'User')

Cierra y abre la terminal y vuelve a probar claude --version.

Arreglar el PATH en macOS

echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

8 · Comprobación final

  • claude --version muestra un número de versión.
  • claude doctor no muestra errores (o tengo captura de los que salen).
  • He iniciado sesión y /status muestra la organización de la empresa.
  • Tengo un repo clonado en el que puedo trabajar sin tocar producción, y sé llegar a él con cd.
  • git --version y node --version funcionan (Node.js 22 o superior).

9 · Opcional: Warp, una terminal más cómoda

No hace falta para el curso. Claude Code funciona igual en PowerShell o en la Terminal de macOS, y en clase usamos esas. Warp es otra terminal, más moderna (pestañas, bloques de salida, mejor copiar y pegar), y Claude Code funciona dentro de ella exactamente igual.

WindowsInstalar

winget install Warp.Warp

O descarga el instalador desde warp.dev.

macOSInstalar

brew install --cask warp

O descarga el .dmg desde warp.dev.

Usar Claude Code dentro de Warp

  1. Abre Warp.
  2. Ve a la carpeta del proyecto con cd.
  3. Escribe claude. Todo lo demás es igual que en esta guía.
Si no se deja instalarSi pide permisos que no tienes o la política de la empresa lo bloquea, déjalo: no lo necesitas. Sigue con PowerShell o con la Terminal.
